# Claude Code 運用基盤 導入計画書

## 概要

thinkbaseリポジトリの運用基盤を参考に、SKhomeプロジェクトにClaude Code運用の仕組みを導入する。

**参考元**: `/Users/suetakeshuuhei/thinkbase/.claude/`

**目的**:
- 定型作業の自動化（コマンド）
- コーディング規約の自動適用（ルール）
- プロジェクト品質の維持（ヘルスチェック）
- 技術情報の陳腐化防止（更新監視）

---

## フェーズ構成

| フェーズ | 内容 | 所要時間目安 |
|---------|------|-------------|
| Phase 1 | ディレクトリ構造の整備 | 1セッション |

## Phase 2: コマンド定義

### 2-1. /health-check（リポジトリ衛生チェック）

**目的**: プロジェクト内の問題を定期的に検出

**チェック項目**:
1. 孤立したコンポーネント（どこからもimportされていない）
2. 未使用の型定義
3. 空のディレクトリ
4. 命名規則違反（PascalCase/camelCase）
5. 'use client' の不適切な使用

**出力形式**:
```
【ヘルスチェック結果】
実行日: YYYY-MM-DD

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔴 要対応（修正必須）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. [問題の説明]
   場所: [ファイルパス]
   推奨対応: [具体的なアクション]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🟡 注意（確認推奨）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🟢 問題なし
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
チェック項目X件すべてパス
```

**ファイル**: `.claude/commands/health-check.md`

**推奨実行頻度**: 週1回、または大きな変更後

### 2-2. /deps-check（依存関係監査）

**目的**: package.jsonの脆弱性・更新状況を確認

**実行内容**:
1. `npm audit` でセキュリティ脆弱性を検出
2. `npm outdated` で古いパッケージを検出
3. 主要パッケージの破壊的変更有無を確認

**チェック対象（主要パッケージ）**:
- next
- react / react-dom
- @supabase/supabase-js
- @anthropic-ai/sdk
- tailwindcss
- typescript
- eslint

**出力形式**:
```
【依存関係監査結果】
実行日: YYYY-MM-DD

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔴 セキュリティ脆弱性
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[npm audit の結果サマリ]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🟡 更新可能なパッケージ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
| パッケージ | 現在 | 最新 | 種別 |
|-----------|------|------|------|
| next | 15.x | 16.x | major |
| ... | ... | ... | ... |

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
推奨アクション
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```

**ファイル**: `.claude/commands/deps-check.md`

**推奨実行頻度**: 月1回

### 2-3. /tech-updates（技術スタック更新チェック）

**目的**: 使用技術の最新情報をチェックし、プロジェクトへの影響を判定

**チェック対象ソース**:

| ソース | URL | 優先度 |
|--------|-----|--------|
| Next.js Blog | https://nextjs.org/blog | 高 |
| React Blog | https://react.dev/blog | 高 |
| Supabase Blog | https://supabase.com/blog | 高 |
| Tailwind CSS Blog | https://tailwindcss.com/blog | 中 |
| Anthropic News | https://www.anthropic.com/news | 中 |

**管理ファイル**: `_config/sources/tech-sources.md`
- 各ソースの `last_checked` を記録
- 更新があった場合のみ詳細確認（トークン節約）

**出力形式**:
