# 依存関係監査

package.jsonの脆弱性・更新状況を確認する。

---

## 目的

依存パッケージのセキュリティ脆弱性と更新状況を定期的にチェックし、プロジェクトの安全性を維持する。

---

## 実行手順

### ステップ1: セキュリティ脆弱性の検出

```bash
npm audit
```

**確認項目**:
- critical: 即時対応必須
- high: 早急に対応
- moderate: 計画的に対応
- low: 把握のみ

---

### ステップ2: 古いパッケージの検出

```bash
npm outdated
```

**確認項目**:
- Current: 現在インストールされているバージョン
- Wanted: package.jsonの範囲内で最新
- Latest: 最新バージョン

---

### ステップ3: 主要パッケージの破壊的変更確認

以下のパッケージについて、メジャーバージョンアップがある場合はCHANGELOGを確認する。

| パッケージ | 用途 |
|-----------|------|
| next | フレームワーク |
| react / react-dom | UI |
| @supabase/supabase-js | データベース |
| @anthropic-ai/sdk | AI連携 |
| tailwindcss | スタイリング |
| typescript | 型システム |
| eslint | コード品質 |

**破壊的変更の確認方法**:
- メジャーバージョンが上がっている場合（例: 15.x → 16.x）
- 公式リリースノートで Breaking Changes を確認

## 自動修復オプション

ユーザー承認後、以下を実行可能:

```bash
# 安全な自動修復（minor/patch のみ）
npm audit fix

# 強制修復（major含む、破壊的変更の可能性あり）
npm audit fix --force
```
