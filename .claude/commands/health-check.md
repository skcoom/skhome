# リポジトリ衛生チェック

プロジェクト内の問題を検出し、コード品質を維持する。

---

## 目的

定期的にプロジェクトの衛生状態をチェックし、問題を早期発見する。

---

## 実行手順

### ステップ1: 孤立コンポーネントの検出

`src/components/` 内のコンポーネントで、どこからもimportされていないものを検出する。

**チェック方法**:
1. `src/components/` 配下の `.tsx` ファイル一覧を取得
2. 各コンポーネント名でプロジェクト全体をGrep
3. import文が1件以下（自分自身のみ）なら孤立と判定

---

### ステップ2: 未使用の型定義の検出

`src/types/` 内の型定義で、どこからも参照されていないものを検出する。

**チェック方法**:
1. `src/types/` 配下の `.ts` ファイルからexportされた型名を抽出
2. 各型名でプロジェクト全体をGrep
3. 参照が1件以下（定義のみ）なら未使用と判定

---

### ステップ3: 空ディレクトリの検出

中身のないディレクトリを検出する。

**チェック方法**:
```bash
find src -type d -empty
```

---

### ステップ4: 命名規則違反の検出

**コンポーネント**: PascalCase（例: `Button.tsx`）
**ユーティリティ**: camelCase（例: `formatDate.ts`）
**ページ**: Next.js規約（`page.tsx`, `layout.tsx`）

**チェック方法**:
- `src/components/` 内で小文字始まりのファイル → 違反
- `src/lib/` 内で大文字始まりのファイル（型定義除く） → 違反

---

### ステップ5: 'use client' の確認

Server Componentで `useState`, `useEffect` 等を使用しているのに `'use client'` がないファイルを検出する。

**チェック方法**:
1. `useState|useEffect|useRef|useCallback|useMemo` を含むファイルを検索
2. そのファイルに `'use client'` があるか確認
3. なければ警告

---
